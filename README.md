# AA计算器

合并计算合租 / AA 开销的小工具

每笔开销记成一行，跑一遍就能得到每个人的净账：负数的人给正数的人打钱即可

## 用法

```sh
lua aa.lua <账本1> <账本2> ...
```

（参数不带扩展名）

## 账本格式

每个账本是一个返回记录列表的 Lua 文件，用 `Pay(付款者, 使用者, 金额)` 构造每一条记录：

```lua
-- log1.lua
return {
    Pay("A", "A B C", 60), -- A 为 A/B/C 垫付 60：A+40 B-20 C-20
    Pay("B", "C", 10),     -- B 为 C 垫付 10：B+10 C-10
}
```

- 付款者：账户 `+金额`
- 使用者：账户 `-金额 / 权重和`，默认平均分摊

增加记录时，只需要记住 `Pay("A","B",...)` 是“A已经为B提供了钱款/服务，B之后要还A”即可

## 加权分摊

付款者和使用者都支持多个人（空格分隔），用 `名字=权重` 指定分摊比例：

```lua
Pay("A=1 B=2", "A=3 B=4 C=5", 100), -- A和B 按权重 1:2 垫付 100，A/B/C 按权重 3:4:5 分摊
```

## 输出

```
$ lua aa.lua log1
净额:
  C -30.00
  B -10.00
  A 40.00
转账方案:
  C -> A 30.00
  B -> A 10.00
尾差（如果存在）:
  D 0.001
```

- `净额`：每个人的净额，正数表示应收（别人欠你），负数表示欠款（你欠别人）
- `转账方案`：把欠款方和应收方贪心配对得到的转账方案，按它逐笔打钱即可结清
- `尾差`：绝对值小于 0.1 的尾差，不计入结算，仅在存在时显示
